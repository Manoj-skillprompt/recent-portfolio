# An accessibility checklist

Accessibility is easiest when it is part of the feature workflow. Test the primary path with a keyboard, use semantic HTML before adding ARIA, and make sure focus indicators remain visible against every surface.

A quick pass at development time is cheaper than rebuilding an interaction after release. It also improves the experience for people using small screens, slow connections, or alternative input devices.
