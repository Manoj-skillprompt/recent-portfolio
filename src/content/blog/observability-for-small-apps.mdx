# Observability for small apps

A small application still needs to tell you when it is unhealthy. Structured JSON logs, request duration, error rate, and a basic uptime check cover a surprising amount of ground.

The goal is not to collect everything. It is to make the most important failures visible and give yourself enough context to fix them quickly.
