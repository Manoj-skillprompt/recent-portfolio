# Finding slow PostgreSQL queries

Performance work starts with evidence. PostgreSQL's EXPLAIN and EXPLAIN ANALYZE commands show whether a query is scanning too many rows, sorting unnecessarily, or missing a useful index.

Measure the query before and after each change. An index that helps one endpoint can add write cost and storage overhead elsewhere, so improvements should be tied to real workloads.
